# QR Code

在浏览器中生成、设计和识别二维码，无需数据库或识别后端。

[在线使用](https://play.wangyifang.com/qrcode/) · [English](./README.en.md)

## 功能

- 生成网址、文字和 Wi-Fi 二维码，支持 PNG、SVG 下载及复制到剪贴板。
- 调整图案、定位框圆角、像素留白、渐变、透明度及 Logo。
- 滑杆与数值输入双向同步，支持一位小数和键盘操作。
- 从图片、拖放、粘贴或摄像头识别二维码。
- 自动保存当前浏览器中的样式，支持跟随系统、亮色和暗色外观。

## 使用

需要 Node.js 20 或更新版本。

```sh
npm ci
npm run build
npm test
npm run dev
```

打开 `http://127.0.0.1:4173/`。`dist/` 为生成的静态文件，可部署到子目录；更新源码后重新构建。

## 说明

使用 React 19、HeroUI v3、Tailwind CSS 4、node-qrcode 和 jsQR。所有可见操作控件使用 HeroUI；二维码设计由标准矩阵生成 SVG。

留白范围为 0–100px，默认 24px；0 即无隐藏边距。滑杆参数范围为 0–100，步长 0.1。导出尺寸滑杆映射为实际像素尺寸，实际尺寸显示在导出区。不透明度支持数字输入；PNG、SVG 保留透明度，预览棋盘底纹不进入导出。

下载文件名为 `内容标识-YYYYMMDDHHmmss.png`（或 `.svg`），时间使用浏览器本地时区。网址仅取域名并去除 `www.`，文字取开头，Wi-Fi 仅取网络名；不将网址路径、查询参数或 Wi-Fi 密码加入名称。内容标识过滤不安全字符，最多 32 个字符且不超过 64 个 UTF-8 字节，完整文件名不超过 83 字节。

PNG 复制为图片。支持 SVG 图像剪贴板的浏览器会同时复制矢量数据和 SVG 源码，其他浏览器复制源码；粘贴方式取决于目标应用。剪贴板及粘贴应用通常不保留文件名，下载时会使用上述名称。权限被拒绝或不支持图片复制时，可改用下载。

直角码点及定位、校正框采用锐利边缘绘制，避免 PNG 中因半像素边缘产生额外灰边；圆角、渐变和半透明仍保留必要的平滑过渡。页面缩放或在其他应用中缩放 PNG 仍可能产生插值。

二维码内容和识别图片在当前页面处理，不上传服务器。样式（含 Logo、导出设置）保存到本机浏览器，二维码内容及 Wi-Fi 密码不写入存储。清除站点数据会删除样式。存储不可用时页面会提示，仍可编辑和导出。

摄像头与剪贴板需要 HTTPS 或 localhost，并受浏览器权限限制。不同设备的相机、剪贴板和识别结果可能不同；大面积 Logo、低对比度和零留白可能影响外部扫码器识别。
